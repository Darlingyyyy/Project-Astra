# 序章：前世梦境 — 逐秒节拍设计

> **版本**: v0.2  
> **状态**: 设计阶段 — 待原型验证  
> **预计时长**: 约 5 分 15 秒（含过场）  
> **设计目标**: 教学 6 项核心操作 + 建立情感锚点 + Boss 首战

---

## 设计目标

| # | 目标 | 验收标准 |
|---|------|----------|
| 1 | 开场 18 秒内建立三人关系悬念 | 测试者主动问"这三个人什么关系？" |
| 2 | 玩家在 30 秒内学会移动 | 不需要文字提示即走向目标 |
| 3 | 首次战斗感觉有力量 | 击中反馈：镜头微震 + 敌人硬直 + 音效 |
| 4 | 技能使用带来"爽"感 | 至少一次 AOE 清屏时刻 |
| 5 | Boss 战有紧张感 | 至少一次"差一点就死了"的体验 |
| 6 | 女主牺牲场景触动情感 | 测试者沉默 3 秒以上 |
| 7 | 醒来后玩家想继续玩 | 第一章开始时的退出率 < 10% |

## 完整节拍表

### 节拍 0 — 开场：击退

| 属性 | 内容 |
|------|------|
| **时间** | 0s – 18s |
| **类型** | 过场动画（不可操作） |
| **音乐** | 开场即战斗高潮的余波——低音弦乐持续轰鸣，远处金属碰撞与嘶吼声不绝（`[PLACEHOLDER]` 参考：FFXVI Eikon 战后的寂静间隙） |

| 秒 | 画面 | 音频 |
|----|------|------|
| 0–2 | 黑屏。一声音爆般的重击——画面瞬间亮起：主角被黑暗神的冲击波正面击中，整个人向后飞出。剑脱手，在空中旋转两圈后插入焦土（距离主角约 8 米）。 | 沉重的撞击声 → 身体落地闷响 + 剑插入地面的金属颤音 |
| 2–4 | 主角趴在地上，画面转为**第一人称视角**。镜头从地面高度仰视——远处，黑暗神的巨大轮廓在暗紫色能量风暴中站立，它的双眼是两团幽冷的紫火。主角的呼吸声沉重，视野边缘有血迹。 | 沉重呼吸声（主角）+ 持续的低频轰鸣（黑暗神的能量场） |
| 4–6 | **第一人称眨眼**：画面短暂暗下（约 0.4s），再睁开。黑暗神仍在原处——不是幻觉，威胁是真实的。这次眨眼后，远处传来一声呼喊的回音，夹杂在风声中几乎听不清。 | 眨眼时短暂的静音（0.3s） → 睁眼后风声 + 喊声的残响 |
| 6–10 | 镜头从第一人称**缓缓摇向右侧**——先扫过剑（插在焦土中，微光闪烁），继续摇，画面中出现两个人影。一位身披法袍的**大法师**，单手持杖，法袍在能量风暴中猎猎作响。他的身旁是一位**少女**（女主），她的长发挥动，神情紧张但坚定。两人的站位紧挨，显然是一起作战的同伴。 | 镜头摇动时，风声减弱，BGM 转入一轨孤独的钢琴高音 |
| 10–12 | 大法师微微侧头，目光从黑暗神的方向收回来，看向地上的主角。他的表情不是温柔，是焦急中带着不容置疑。他开口——声音穿透风声，干脆利落。**「站起来，愣着干嘛，你要给对面机会吗？」** | 大法师的台词清晰、不拖泥带水。嗓音特质：30 岁左右，低沉但不苍老，语气是战场上习惯发号施令的人。 |
| 12–14 | 大法师说完后，女主的目光也落向主角。她没有说话，但那一瞬间的眼神里有关切、有不舍——不是普通的战友。她嘴角微启似乎想说什么，但最终克制住了，只是轻轻点了下头。 | 大法师台词的回响渐弱，BGM 钢琴音转为柔和的弦乐（女主的主题旋律的碎片） |
| 14–16 | 镜头切回主角。他的拳头砸向地面，焦土碎裂。他撑起身体——先单膝，再站直。镜头随他升起，从地面仰角变为平视。主角的眼神从迷茫转为坚定。 | 拳头砸地（重低音） → 心跳声启动（1 拍/秒） → 站直时心跳骤停 → 一声深沉的呼吸 |
| 16–18 | 主角完全站起。他看向剑（方向提示），剑身开始发出微弱的金色光芒——仿佛在呼应他。此时画面定格 0.5s，给玩家一瞬的视觉锚点。 | 剑发光时一声音效（类似金属轻鸣，持续时间 < 1s），心跳声消失，战斗 BGM 的低音线条开始渐入 |

**此节拍的情绪曲线**:
```
倒地(无助) → 确认威胁(恐惧) → 同伴的声音(被唤醒)
→ 女主的眼神(被牵挂) → 站起(决心) → 剑的呼应(准备战斗)
```

**为什么这样开场**:
| 设计意图 | 实现方式 |
|----------|----------|
| **三人在第一秒同框** | 不是逐个介绍，而是一次性抛出。观众自然会想："这三个人什么关系？" |
| **大法师一句立住性格** | 不是"你没事吧？"而是"愣着干嘛"——他是军人/指挥官思维，不是在安慰战友，是在催促战斗。 |
| **女主的沉默是叙事** | 她不说台词，但眼神里有关切和克制。观众会注意到："她为什么忍住不说话？"这是恋爱线的第一个伏笔。 |
| **第一人称眨眼** | 打破第三人称惯例，给玩家一瞬的沉浸感。眨眼也是"确认自己还活着"的生理隐喻。 |
| **剑被击飞不是拔起** | 主角不是"找到武器"而是"夺回武器"。心理动力完全不同——一个是探索，一个是复仇。 |

**视觉参考** `[PLACEHOLDER]`:
- 黑暗神的轮廓：类似 Genshin「深渊使徒」的体型 × 《艾尔登法环》「拉达冈」的能量气场
- 第一人称血迹边缘：参照《战神》奎托斯受伤时的 HUD 处理——模糊但不遮挡信息
- 剑插焦土的构图：参照《塞尔达传说》大师剑的场景——剑不是武器，是希望

**边缘情况**: 
- 玩家按跳过 → 直接跳到节拍 1 开头（主角已站起，控制权交给玩家）。但跳过时保留大法师的台词字幕，确保玩家知道"有人在催我"
- 此节拍中女主和大法师均无面部特写——保持神秘感，五官留给后续剧情逐步揭示

### 节拍 1 — 教学：移动与拔剑

| 属性 | 内容 |
|------|------|
| **时间** | 18s – 32s |
| **类型** | 游戏操作（教学） |
| **音乐** | 弦乐持续，打击节奏轻微渐入。拔剑瞬间 BGM 加入第一声战鼓重击。 |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 18 | 控制权交给玩家。主角站在原地，大法师和女主在身后约 3 米处（不出现在画面中但存在于世界内，玩家回头可以看到他们——大法师维持警戒姿态，女主轻轻握拳）。前方 8 米处，剑插在焦土中，金色微光脉冲（每秒 1 次）。 | 屏幕下方出现半透明提示：**「左摇杆 / WASD — 移动」**（3 秒后自动消失）。提示位置偏下，不遮挡剑的光芒。 |
| 18–24 | 主角走向剑。如果玩家不走，5 秒后大法师在身后低声说了一句「快点」，同时剑的光芒脉冲频率加速（1 次/秒 → 2 次/秒），作为双重引导。 | 移动距离: 约 8m，预计耗时 3–5s。如果玩家 15 秒仍未走到剑前 → 触发文字提示：「夺回你的剑……」 |
| 24–28 | 主角走到剑前。剑身的金色光芒从脉冲变为持续发光。右手靠近剑柄时，金色粒子从剑身流向手指——剑在呼应他。 | 屏幕提示：**「按 F / Y — 交互」** |
| 28–32 | 主角拔剑。剑脱离地面的瞬间，一道金色冲击波沿地面扩散（半径 4m，纯装饰，无伤害）。剑的光芒沿手臂流遍全身——主角的站姿从"刚爬起来的伤员"变为"握剑的战士"。 | 拔剑动画约 2.5s。FOV 微增（75 → 80），给玩家"我准备好了"的感觉。拔剑后 HUD 右下角技能图标首次亮起。 |

**教学成功标准**: 玩家从站起到拔剑，全程不需要文字以外的帮助。拔剑后的站姿变化是无声的确认——"你不再是倒地的那个人了"。
**叙事包袱**: 拔剑的瞬间，大法师和女主的存在退到背景中。此时焦点完全在主角身上——这是他的时刻。

**边缘情况**:
- 玩家朝反方向走 → 相机轻轻拉回（不给硬边界），同时剑的光芒增强。若玩家走到大法师面前，他皱眉说「你在看哪里？」
- 玩家尝试攻击（未拔剑时） → 主角做出空手推开的无效动作，剑的光芒脉冲引导
- 玩家 30 秒内仍未拔剑 → 触发系统辅助：镜头自动转向剑 + 大法师：「需要我帮你捡吗？」
- 玩家回头看向女主 → 她微不可察地点了下头（不给文字、不给 UI）——这是留给细心玩家的彩蛋

|------|------|
| **时间** | 32s – 52s |
| **类型** | 游戏操作（教学） |

| 秒 | 画面 | 操作 / 教学 |

| 32–39 | 玩家靠近并攻击。每个残影承受 **3 次普攻**即消散（`[PLACEHOLDER]` HP=30, 每刀伤害=12）。 | 连击：轻→轻→轻（三段动作），第三段为横扫，有轻微击退。音效：金属命中（sharp）+ 敌人消散（whoosh）。 |
| 39–44 | 三个残影清完后，地面再次震颤——更大范围，6 个残影分批出现：先 3 个（前方），3 秒后另 3 个（侧面）。 | 不给新提示，让玩家自己打。 |

**连击手感调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 调校方向 |
|------|--------|----------|
| 第一段前摇 | 0.15s | 太快 = 无重量感 / 太慢 = 迟钝 |
| 第二段前摇 | 0.25s | 需比第一段稍慢，建立节奏 |
| 第三段前摇 | 0.45s | 最慢，但伤害最高（×1.5） |
| 第三段伤害 | 18 | 确保能一刀补掉残血敌人 |
| 攻击硬直（敌人） | 0.3s | 每次命中让敌人短暂停顿 |
| 攻击后摇 | 0.2s | 闪避可取消后摇 |

**边缘情况**:
- 玩家全程不攻击 → 残影缓慢靠近但不造成伤害（教学保护），20s 后强制进入下一个节拍（残影自行消散，视为"击退"）
- 玩家站在原地挨打 → 残影攻击力=0（此节拍不掉血）

### 节拍 3 — 教学：技能

| 属性 | 内容 |
|------|------|
| **时间** | 52s – 74s |
| **类型** | 游戏操作（教学） |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 52 | 更大范围震颤。前方 20 米处，地面裂开——**8 个残影**同时爬出，呈扇形散开向英雄逼近。 | 屏幕提示：**「按 E / Y — 技能：辉光斩」**（持续显示，直到玩家使用）HUD 右下角技能图标亮起并脉冲。 |
| 52–62 | 玩家按技能键 → 英雄将剑刺入地面 → 以英雄为圆心，半径 6m 的金色冲击波扩散（AOE）。范围内残影全部直接消散。 | 技能动画约 1.5s（前摇 0.6s + 释放 0.9s）。释放期间英雄无敌。特效：地面裂纹 + 金色波环 + 残影灰飞烟灭的粒子。 |
| 62–66 | 光波消散，战场短暂安静。英雄喘一口气（微微躬身）。 | 无操作，纯喘息动画（1.5s）。让玩家消化"刚才很爽"的感受。 |
| 66–74 | 连续清了两波敌人后，英雄体力不支。屏幕边缘出现暗红色晕影（模拟虚弱感）。HUD 显示 HP 条首次出现，当前 HP=80%（`[PLACEHOLDER]`）。 | 无提示。HUD 淡入是"真正的战斗现在开始"的信号。 |

**技能调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| 技能冷却 | 8s | 防止连发，同时不觉得等太久 |
| AOE 范围 | 半径 6m | 刚好覆盖"感觉一大片"的最小范围 |
| AOE 伤害 | 50（秒杀杂兵） | 教学关数值不必严谨，要的是"爽" |
| 技能前摇 | 0.6s | 有蓄力感但不拖沓 |
| 释放无敌帧 | 全动画 | 避免"放大招被小兵打断"的挫败 |

**边缘情况**:
- 玩家持续不用技能 → 残影 15s 内靠近后真的造成伤害（每次 5 HP），给压迫感
- 玩家用普攻一个个打 → 也行，但效率极低。打完第 4 个后，剩余残影会加速，暗示"你需要技能"
- 如果玩家被残影打到 HP=0 → HP 锁在 1，触发紧急提示「按 E 使用技能！」

### 节拍 4 — 教学：闪避 + 强力敌人

| 属性 | 内容 |
|------|------|
| **时间** | 74s – 99s |
| **类型** | 游戏操作（教学） |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 74 | 地面**剧烈**震颤。前方 20 米处，一只「深渊重甲兵」（约 3 倍英雄身高，持巨斧的大型敌人）从裂缝中爬出。地面震动传递到手柄。 | 提示：**「按 Shift / B — 闪避」**。大型敌人的头顶出现**红色预警光环**——这是全游戏统一的"可闪避攻击"标识。 |
| 76–82 | 重甲兵举起巨斧，**蓄力 2 秒**后砸下——地面出现红色圆形预警范围（半径 3m）。 | 玩家需要在蓄力完成前闪避出红圈。闪避成功 → 英雄翻滚至安全距离。闪避失败 → 受到 25 点伤害（约 25% HP），英雄被击退 5m。 |
| 82–89 | 重甲兵追上来，再次蓄力。这次蓄力更快（1.2s）。 | 第二次闪避练习。 |
| 89–94 | 重甲兵砸地后巨斧卡入地面 1.5s（硬直窗口）。此时重甲兵身上出现金色裂纹——提示"可以反击"。 | 不给文字提示，玩家自然理解"他动不了 = 我该打"。 |
| 94–99 | 玩家攻击硬直中的重甲兵 → 伤害 ×1.5。连击一套后重甲兵消散。 | 首次完整的"闪避→反击"循环完成。音效：巨斧砸地（低沉）+ 反击命中（清脆）。 |

**闪避调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| 闪避无敌帧 | 0.25s | 核心手感参数 |
| 闪避距离 | 5m | 足够避开半径 3m 的红圈 |
| 闪避冷却 | 0.5s（可连闪） | 允许连续闪避 |
| 敌蓄力时间（首次） | 2s | 给充足反应时间 |
| 敌蓄力时间（后续） | 1.2s | 加快节奏 |
| 敌硬直窗口 | 1.5s | 够打一套普攻 |

**边缘情况**:
- 玩家不闪避，硬吃伤害 → HP 降至 ~55%。不死，但屏幕晕影加重。此时重甲兵的下一次蓄力延长至 3s（游戏暗自降低难度）
- 被击中后 → 玩家获得 2s 的伤害免疫窗口，防止被连续击倒
- 玩家跑到远处（>30m） → 重甲兵缓慢追击，速度=英雄步行速度的 80%

### 节拍 6 — Boss 战：黑暗神 · 阶段一

| 属性 | 内容 |
|------|------|

#### Boss 机制 — 阶段一

| 参数 | 值 | 说明 |
|------|-----|------|
| HP | 300 `[PLACEHOLDER]` | 约 45–60s 可击破 |
| 攻击模式 | 2 种，轮流使用 | |
| 模式 A：暗影冲击 | 黑暗神从空中射出一束暗紫色能量柱，落点有 1.5s 红圈预警 | 半径 4m，伤害 30，冷却 8s |
| 模式 B：触手横扫 | 黑暗神挥舞触手横扫战场半场（左→右或右→左） | 伤害 25，需向触手方向闪避（穿过去）或后撤 |

#### Boss 行为循环

```
暗影冲击 → 等待 3s → 触手横扫 → 等待 3s → 暗影冲击 → ...
```
每次攻击后 Boss 有 **3s 硬直**，头部核心暴露——这是输出窗口。

#### 玩家操作节奏

| 阶段 | 动作 | 时长 |
|------|------|------|
| 躲技能 | 闪避暗影冲击 / 触手横扫 | ~2s |
| 输出窗口 | 接近 Boss 核心，普攻 + 技能 | ~3s（CD 好时放技能） |
| 拉开距离 | Boss 重新开始攻击前摇 | ~1s |

完整循环：约 6–7s。

**关键体验**: 玩家应该在这个阶段感到"我能读懂它的攻击了"——从紧张到有掌控感。

**数值调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| Boss HP | 300 | 单次循环伤害约 30，约 10 个循环击破 |
| 玩家普攻 DPS | 15/循环 | 3s 窗口 × 3 段 ≈ 15 |
| 玩家技能伤害 | 40/次 | CD 8s，每个循环放不出来——每 2 循环放一次 |
| Boss 暗影冲击伤害 | 30 (30% HP) | 有威胁但不致命 |
| Boss 横扫伤害 | 25 | 略低，因为是更难躲的范围技 |

**边缘情况**:
- 玩家 HP 降至 0 → 此 Boss 战 HP 锁在 1（这是教学关的最终 Boss 第一阶段，不在这让玩家死）
- 玩家长时间不攻击（>15s） → Boss 攻击频率降低，给玩家喘息空间
- HP 降至 50% → Boss 攻击间隔从 6s 缩短到 4s，给玩家"它在变强"的感觉

### 节拍 7 — Boss 战：黑暗神 · 阶段二（暴走）

| 属性 | 内容 |
|------|------|
| **时间** | 179s – 234s |
| **类型** | Boss 战（阶段二） |
| **音乐** | BGM 变化：加入急板弦乐 + 不和谐音 `[PLACEHOLDER]` |

#### 转阶段演出（179s–184s）

| 秒 | 画面 |
|----|------|
| 179 | HP 归零 → Boss 并未倒下，而是发出震耳欲聋的怒吼。屏幕震动 3s。 |
| 180–182 | Boss 的暗紫色身体边缘燃起黑色火焰。模型体积增大 20%。天空完全变暗。 |
| 182–184 | Boss HP 条重置——**但这次是黑色底 + 红色边框**（视觉信号：更危险）。新 HP=200。 |

#### 阶段二新增机制

| 新增攻击 | 描述 | 预警 | 伤害 |
|----------|------|------|------|
| **模式 C：暗影分裂** | Boss 分裂出 2 个小型残影（HP=20/个），从两侧夹击英雄 | 地面出现两个小紫圈 | 每个 10 |
| **模式 D：深渊之握** | 地面随机出现 3 个紫色漩涡，1s 后爆炸 | 紫色漩涡旋转加速 | 每个 20 |

阶段二的循环变为混沌模式：**3 种攻击随机排列**（不再是固定循环），每 3–5s 一次攻击。

#### 玩家体验设计

阶段二不能给玩家"规律的掌控感"——要的是**压迫**。角色 HP 在这个阶段应该降到 30–50%。

但因为是教学关，加入一个隐性帮助：
- 玩家 HP 降至 20% 以下时 → Boss 的下一次攻击必然有 0.5s 额外延迟
- 给玩家"我以为要死了……但居然躲开了"的体验

**暴走阶段调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| Boss HP | 200 | 略少于阶段一，但容错更低 |
| 攻击间隔 | 3–5s（随机） | 比阶段一更紧凑 |
| 分裂残影 HP | 20 | AOE 技能可清 |
| 分裂残影伤害 | 10/次 | 不算高，但干扰节奏 |
| 漩涡爆炸范围 | 3m 半径 | 需要移动避开 |

**边缘情况**:
- 玩家在阶段二中真死了 → 回到阶段二开头（Boss HP=200），不从头开始。这是教学关的底线。
- 所有技能 CD 在重试时重置。

## 技术需求

### 场景
- 古代战场：直径约 80m 的圆形竞技区域。材质：焦土 + 裂谷缝隙（发暗紫色光）。天空：动态 skybox，暗紫色能量风暴。
- 边界处理：战场边缘为悬崖 / 能量墙（透明的暗紫色屏障），碰到有视觉反馈（波纹），但不会把玩家弹回去——改成玩家自动转身。

### 角色
- **古代英雄**: 沿用了主角的基础骨骼。穿残破铠甲。武器：一把发光长剑。
- **女主**: 白色长袍，长发发光。仅过场出现，无需战斗动作。
- **深渊残影**: 小型敌人，基础 AI 跟随 + 近战。
- **深渊重甲兵**: 大型敌人，2 种 AI 行为（蓄力砸地 + 硬直）。
- **黑暗神**: 大型 Boss，场景绑定（不移动），多阶段 AI。

### 相机
- 探索/战斗：第三人称自由视角，默认距离 5m
- 拔剑瞬间：FOV 75→80
- 技能释放：FOV 短暂提升至 85（0.3s 缓动）
- 过场：完全镜头控制（引擎的 Sequencer / Timeline）

### HUD
- 序章期间：极简 HUD——仅教学提示，无 HP 条（节拍 3 才出现）
- 节拍 3 后：HP 条 + 技能图标 + Boss HP 条
- 第一章开始：完整 HUD
