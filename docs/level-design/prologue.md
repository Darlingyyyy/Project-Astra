# 序章：前世梦境 — 逐秒节拍设计（三人小队版）

> **版本**: v0.3  
> **状态**: 设计阶段 — 待原型验证  
> **预计时长**: 约 5 分 55 秒（355 秒，含过场）  
> **设计模式**: 三人小队 · 独立血条 · 自由切换  
> **设计目标**: 教学 8 项核心操作 + 建立三人关系悬念 + 女主牺牲情感锚点 + Boss 首战

---

## 设计目标

| # | 目标 | 验收标准 |
|---|------|----------|
| 1 | 开场 18 秒内建立三人关系悬念 | 测试者主动问「这三个人什么关系？」 |
| 2 | 玩家在 30 秒内学会移动 | 不需要文字提示即走向目标 |
| 3 | 首次切换角色感到自然 | 测试者主动尝试切换第二个角色 |
| 4 | 首次战斗感觉有力量 | 击中反馈：镜头微震 + 敌人硬直 + 音效 |
| 5 | 三人协同有战术感 | 测试者自发切换角色应对不同局面 |
| 6 | Boss 战有紧张感 | 至少一次「差一点就死了」的体验 |
| 7 | 女主牺牲触动情感 | 测试者沉默 3 秒以上 |
| 8 | 醒来后玩家想继续玩 | 第一章开始时的退出率 < 10% |

## 完整节拍表

### 节拍 0 — 开场：击退（含伏笔）

| 属性 | 内容 |
|------|------|
| **时间** | 0s – 18s |
| **类型** | 过场动画（不可操作） |
| **音乐** | 开场即战斗高潮的余波——低音弦乐持续轰鸣，远处金属碰撞与嘶吼声不绝（`[PLACEHOLDER]` 参考：FFXVI Eikon 战后的寂静间隙） |

| 秒 | 画面 | 音频 |
|----|------|------|
| 0–2 | 黑屏。一声音爆般的重击——画面瞬间亮起：黑暗神释放第一波暗属性冲击波。**前世英雄**被正面击中，整个人向后飞出，剑脱手插入焦土（距离约 8 米）。**大法师**被冲击波推开三步，法杖撑地稳住。**女主**——却只是**踉跄了一步**，手按住胸口，眉头微皱但没倒下。她没有说话，黑暗神也没有注意到她。 | 沉重的撞击声 → 身体落地闷响 + 剑插入地面的金属颤音 |
| 2–4 | 主角趴在地上，画面转为**第一人称视角**。镜头从地面高度仰视——远处，黑暗神的巨大轮廓在暗紫色能量风暴中站立，它的双眼是两团幽冷的紫火。主角的呼吸声沉重，视野边缘有血迹。 | 沉重呼吸声（主角）+ 持续的低频轰鸣（黑暗神的能量场） |
| 4–6 | **第一人称眨眼**：画面短暂暗下（约 0.4s），再睁开。黑暗神仍在原处——不是幻觉，威胁是真实的。 | 眨眼时短暂的静音（0.3s）→ 睁眼后风声 + 喊声的残响 |
| 6–10 | 镜头从第一人称**缓缓摇向右侧**——先扫过剑（插在焦土中，微光闪烁），继续摇，画面中出现两个人影。大法师单手持杖，法袍在能量风暴中猎猎作响。女主站在他身旁，长发挥动，神情紧张但坚定——她刚稳住身形，正在看向主角。 | 镜头摇动时，风声减弱，BGM 转入一轨孤独的钢琴高音 |
| 10–12 | 大法师微微侧头，目光从黑暗神的方向收回来，看向地上的主角。**「站起来，愣着干嘛，你要给对面机会吗？」** | 大法师的台词清晰、不拖泥带水。嗓音：30 岁左右，低沉但不苍老。 |
| 12–14 | 女主的目光也落向主角。她嘴角微启似乎想说什么——但最终克制住了。刚才被冲击波击中时她本应倒下的，现在却已经站稳。她什么都不说，只是轻轻点了下头。 | BGM 钢琴音转为柔和弦乐（女主的主题旋律碎片） |
| 14–16 | 镜头切回主角。拳头砸向地面，焦土碎裂。撑起身体——先单膝，再站直。镜头随他升起，从仰角变为平视。眼神从迷茫转为坚定。 | 拳头砸地（重低音）→ 心跳声（1 拍/秒）→ 站直时一声深沉的呼吸 |
| 16–18 | 主角完全站起。看向剑（方向提示），剑身发出微弱的金色光芒——仿佛在呼应他。画面定格 0.5s。 | 剑发光时一声音效（金属轻鸣 < 1s），心跳消失，战斗 BGM 低音渐入 |

**此节拍的情绪曲线**:
```
倒地(无助) → 确认威胁(恐惧) → 同伴的声音(被唤醒)
→ 女主的眼神(被牵挂) → 站起(决心) → 剑的呼应(三人准备迎战)
```

**伏笔植入**:
| 伏笔 | 位置 | 回响 |
|------|------|------|
| 女主只踉跄一步 | 0-2s | 节拍 8 揭示：她体内有与黑暗神同源的暗属性 |
| 女主克制不语 | 12-14s | 第一章起贯穿：她的沉默是有原因的 |

**边缘情况**:
- 玩家按跳过 → 直接跳到节拍 1 开头（控制权交给玩家），但保留大法师台词字幕
- 此节拍中女主和大法师均无面部特写——保持神秘感

### 节拍 1 — 教学：移动与拔剑

| 属性 | 内容 |
|------|------|
| **时间** | 18s – 32s |
| **类型** | 游戏操作（教学） |
| **音乐** | 弦乐持续，打击节奏轻微渐入。拔剑瞬间 BGM 加入第一声战鼓重击。 |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 18 | 控制权交给**前世英雄**。大法师和女主在身后约 3 米处（可回头看到——大法师维持警戒姿态，女主轻轻握拳）。前方 8 米处，剑插在焦土中，金色微光脉冲（每秒 1 次）。 | 屏幕下方半透明提示：**「WASD — 移动」**（3s 后自动消失） |
| 18–24 | 走向剑。如果 5s 不动，大法师低声说「快点」，同时剑光芒脉冲加速（1→2 次/秒）。 | 移动距离约 8m，预计 3-5s。15s 未到 →「夺回你的剑……」 |
| 24–28 | 走到剑前。剑身金光从脉冲变为持续发光。金色粒子从剑身流向手指。 | 屏幕提示：**「按 E — 交互」** |
| 28–32 | 拔剑。剑脱离地面瞬间，金色冲击波沿地面扩散（半径 4m，纯装饰）。剑的光芒沿手臂流遍全身——站姿从「刚爬起来的伤员」变为「握剑的战士」。 | 拔剑约 2.5s。FOV 微增（75→80）。HUD 右下角技能图标首次亮起。 |

**叙事包袱**: 拔剑的瞬间，三人的站位形成了战斗阵型——英雄在前，法师在左后，女主在右后。

### 节拍 2 — 教学：切换角色 + 法师远程战斗

| 属性 | 内容 |
|------|------|
| **时间** | 32s – 55s |
| **类型** | 游戏操作（教学） |
| **新增教学** | 切换角色（首次引入） |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 32 | 拔剑后地面震颤。前方 10 米处，5 个「深渊残影」从裂缝中爬出——其中 3 个近战型靠近，2 个原地投射暗弹。 | 屏幕提示：**「鼠标左键 — 普攻」**（持续 2s 后消失） |
| 32–38 | 玩家以英雄攻击近身残影。近战残影承受 3 次普攻消散。但远程残影持续投射暗弹——英雄难以接近。 | — |
| 38 | 大法师在身后喊：「让我来。」 | 屏幕提示：**「按 2 — 切换至大法师」**（持续显示，直到玩家切换）HUD 左上角队伍头像中，法师头像亮起脉冲边框。 |
| 38–42 | 切换至大法师。镜头平滑过渡。大法师落地时脚下有小型奥术符文（入场特效）。 | 切换无敌帧 0.5s。HUD 技能栏切换为法师技能组。 |
| 42–48 | 操控大法师，用火球术（Q）远程点掉两个投射残影。 | 提示：**「按 Q — 火球术」**。远程击杀有不同音效（爆裂声）。 |
| 48–55 | 剩余近战残影靠近。大法师用冰霜新星（E）冻结 + 火球收割。 | 提示：**「按 E — 冰霜新星」**（自然衔接）。清场后短暂停顿。 |

**教学要点**: 玩家首次体验「不同角色解决不同问题」——英雄打近战、法师打远程。这是队伍切换的核心乐趣。

**边缘情况**:
- 玩家 10s 不切换 → 大法师自动接手打掉远程残影（但英雄 HP 会被暗弹压低，作为软压力）
- 切换后原本的英雄由 AI 操控，持续攻击近战残影

### 节拍 3 — 教学：切回英雄 + 辉光斩

| 属性 | 内容 |
|------|------|
| **时间** | 55s – 75s |
| **类型** | 游戏操作（教学） |
| **新增教学** | 切回英雄 + 技能 AoE 使用 |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 55 | 更大范围震颤。前方 20 米处，地面裂开——**8 个残影**呈扇形散开逼近。 | 屏幕提示：**「按 1 — 切换至英雄」**。英雄头像脉冲。 |
| 55–60 | 切回英雄，走向敌群。 | 不给新提示，让玩家自己决定怎么打。 |
| 60 | 残影密集逼近。 | 屏幕提示：**「按 Q — 辉光斩」**（持续直到使用）。技能图标脉冲。 |
| 60–72 | 按 Q → 英雄将剑刺入地面 → 以英雄为圆心，半径 6m 金色冲击波扩散。范围内残影全部直接消散。 | 技能动画约 1.5s（前摇 0.6s + 释放 0.9s）。释放期间无敌。特效：地面裂纹 + 金色波环 + 粒子消散。 |
| 72–75 | 光波消散，战场短暂安静。英雄喘一口气（微微躬身）。 | 喘息动画 1.5s，让玩家消化「刚才很爽」的感受。 |

**关键体验**: 这是玩家的第一个「AoE 清屏时刻」——切换到英雄、一个大招全清。这是三人小队的战术节奏：用法师远程压制 → 切英雄近身收割。

**边缘情况**:
- 玩家持续不用技能 → 残影 15s 内靠近后造成伤害（每次 5 HP）
- 玩家 HP 降至 0 → HP 锁在 1，强制提示「按 Q 使用辉光斩！」

### 节拍 4 — 教学：女主登场 + 辅助技能 + 闪避

| 属性 | 内容 |
|------|------|
| **时间** | 75s – 100s |
| **类型** | 游戏操作（教学） |
| **新增教学** | 切换至辅助角色 + 护盾/易伤 + 闪避 |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 75 | 地面**剧烈**震颤。前方 20 米处，**深渊重甲兵**（约 3 倍英雄身高，持巨斧）从裂缝中爬出。同时两侧各有 2 个残影。 | 屏幕提示：**「按 3 — 切换至女主」**。女主头像首次高亮脉冲。 |
| 75–80 | 切换到女主。镜头拉近——女主的长发泛着微光，她轻吸一口气，双手结印。 | 切换无敌帧 0.5s。HUD 技能栏切换为女主 2 技能组。女主模型首次进入玩家操控。 |
| 80–84 | 重甲兵举起巨斧蓄力（2s），地面出现红色圆形预警范围（半径 3m）。同时残影从两侧逼近。 | 提示：**「按 Shift — 闪避」**。 |
| 84 | 如果玩家闪避成功 → 女主轻盈后跃。如果被击中 → 女主被击退（伤害 25），但此时不给任何惩罚——第一次教学允许失败。 | — |
| 84–89 | 重甲兵巨斧卡入地面 1.5s（硬直窗口）。 | 屏幕提示：**「按 E — 弱点标记」**。 |
| 89–94 | 女主对重甲兵释放弱点标记——敌人身上出现金色准星标记，全队伤害 +25%。 | 提示：**「按 Q — 守护之盾」**。 |
| 94–100 | 女主给英雄上盾。提示：**「按 1 — 切回英雄」**。切回英雄后，身上有护盾光效，冲向硬直中的重甲兵——带着弱点标记 + 护盾的安全感，一套普攻带走。 | 完整的「辅助→切换→收割」循环完成。 |

**关键体验**: 玩家首次体验辅助角色的价值——不是直接输出，而是让输出更强。这是三人小队战术深度的起点。

**女主的操控感**: 她比英雄轻（移动速度 +10%），闪避距离 +1m，但普攻伤害只有英雄的 40%。玩家操控她时会自然理解「她是辅助，不是输出」。

### 节拍 5 — 自由战斗：三人协同

| 属性 | 内容 |
|------|------|
| **时间** | 100s – 125s |
| **类型** | 游戏操作（无教学提示） |
| **教学目的** | 让玩家自由尝试三人切换，不引导、不提示 |

| 秒 | 画面 | 玩法 |
|----|------|------|
| 100 | 重甲兵消散后，战场短暂安静。 | 无任何提示。HUD 完整显示（三人 HP + 技能栏）。 |
| 100–110 | 地面多处裂缝——前方 3 个近战残影 + 左侧 2 个投射残影 + 右侧 1 个重甲兵。 | 玩家自由选择：用英雄硬扛？用法师远程清？用女主标记+盾辅助？ |
| 110–125 | 敌人逐渐增多，节奏加快。如果玩家一直不切换 → 当前角色 HP 持续下降（独立血条）。 | 这是第一次真正意义上的「如果不切换可能会死」的软压力。 |

**设计意图**: 这是全部教学完成后的「自由练习」——给玩家 25 秒消化刚才学的切换、技能、闪避循环。同时也是节拍 6 Boss 战前的热身。

**边缘情况**:
- 任一角色 HP 降至 0 → 该角色倒下（无法操控），剩余角色继续战斗。15s 后倒下的角色以 20% HP 复活
- 三个角色同时倒下 → 战斗失败，从节拍 5 重新开始

### 节拍 6 — Boss 战：黑暗神 · 阶段一

| 属性 | 内容 |
|------|------|
| **时间** | 125s – 210s |
| **类型** | Boss 战（阶段一）· 三人协同 |
| **音乐** | Boss 战 BGM：快速打击乐 + 弦乐短句循环 `[PLACEHOLDER]` |

#### 转阶段演出（125s–130s）

| 秒 | 画面 |
|----|------|
| 125–127 | 最后一只精英怪消散的粒子倒流——被吸向前方。 |
| 127–130 | 黑暗神的完整形态在能量风暴中显现。**BOSS 名称卡**出现：「黑暗神 · 深渊之主」。 |

#### Boss 机制 — 阶段一

| 参数 | 值 | 说明 |
|------|-----|------|
| HP | 450 `[PLACEHOLDER]` | 三人输出下约 60-80s 可击破 |
| 触发转阶段 | HP ≤ 150（1/3） | 进入节拍 7 过场 |
| 攻击模式 | 3 种 | |

| 攻击 | 描述 | 预警 | 伤害 | 冷却 |
|------|------|------|------|------|
| 暗影冲击 | 空中射下暗紫色能量柱 | 红圈 1.5s | 30 | 8s |
| 触手横扫 | 触手半场横扫 | Boss 侧身 1.2s | 25 | 10s |
| 深渊之握 | 地面 3 个紫色漩涡，1s 后爆炸 | 旋转加速 | 20/个 | 12s |

每次攻击后 Boss 有 3s 硬直，头部核心暴露——输出窗口。

#### 三人协同策略

| 角色 | Boss 阶段一职责 |
|------|-----------------|
| 英雄 | 硬直窗口近身输出（辉光斩 + 普攻） |
| 法师 | 远程持续输出，Boss 攻击间隙用雷击弹跳清杂兵 |

**数值调校** `[PLACEHOLDER]`:
| 参数 | 初始值 |
|------|--------|
| Boss HP | 450 |
| 三人总 DPS（轮流输出） | 约 8-10/循环 |

**关键体验**: 玩家应该在阶段一建立「三人切换的节奏感」——标记→上盾→切英雄输出→闪避→切法师远程→再切回。

**边缘情况**:
- 任一角色 HP 降至 0 → 倒下，15s 后 20% HP 复活
- 三人都倒下 → 从阶段一重新开始（Boss HP 重置为 450）

## 技术需求

### 场景
- 古代战场：直径约 80m 的圆形竞技区域。材质：焦土 + 裂谷缝隙（发暗紫色光）。天空：动态 skybox，暗紫色能量风暴。
- 边界处理：战场边缘为能量墙（透明的暗紫色屏障），碰到有视觉反馈（波纹），自动转身。

### 角色
- **前世英雄**: 沿用了主角的基础骨骼。穿残破铠甲。武器：一把发光长剑。
- **大法师**: 法袍 + 单手法杖。需要基本战斗动画（远程施法 + 切换出场）。
- **女主**: 白色长袍，长发发光。需要基本战斗动画（上盾 + 标记 + 闪避）。过场中需要封印特效联动。
- **深渊残影**: 小型敌人，基础 AI 跟随 + 近战 / 投射两种变体。
- **深渊重甲兵**: 大型敌人，2 种 AI 行为（蓄力砸地 + 硬直）。
- **黑暗神**: 大型 Boss，场景绑定（不移动），多阶段 AI。

### 相机
- 探索/战斗：第三人称自由视角，默认距离 5m
- 切换角色：平滑过渡（0.3s 缓动），非硬切
- 过场：完全镜头控制（引擎的 Sequencer / Timeline）
- 拔剑瞬间：FOV 75→80
- 技能释放：FOV 短暂提升至 85（0.3s 缓动）

### HUD
- 序章期间：逐步解锁 HUD 元素
  - 节拍 1：仅教学提示
  - 节拍 2：左上角队伍头像出现（三人），右下角技能栏出现
  - 节拍 3：三人 HP 条全部显示
  - 节拍 5：完整战斗 HUD
- 第一章开始：完整 HUD（含小地图、任务提示）
