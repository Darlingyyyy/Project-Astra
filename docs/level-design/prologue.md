# 序章：前世梦境 — 逐秒节拍设计

> **版本**: v0.1  
> **状态**: 设计阶段 — 待原型验证  
> **预计时长**: 约 5 分钟（含过场）  
> **设计目标**: 教学 6 项核心操作 + 建立情感锚点 + Boss 首战

---

## 设计目标

| # | 目标 | 验收标准 |
|---|------|----------|
| 1 | 玩家在 30 秒内学会移动 | 不需要文字提示即走向目标 |
| 2 | 首次战斗感觉有力量 | 击中反馈：镜头微震 + 敌人硬直 + 音效 |
| 3 | 技能使用带来"爽"感 | 至少一次 AOE 清屏时刻 |
| 4 | Boss 战有紧张感 | 至少一次"差一点就死了"的体验 |
| 5 | 女主牺牲场景触动情感 | 测试者沉默 3 秒以上 |
| 6 | 醒来后玩家想继续玩 | 第一章开始时的退出率 < 10% |

| 属性 | 内容 |

| **类型** | 过场动画 |

| 秒 | 画面 | 音频 |
|----|------|------|
| 6–8 | 镜头从高空俯冲下降，聚焦一个倒在地上的身影（古代英雄，身披残破铠甲）。 | 风声渐弱，心跳声（1 拍/秒）渐入 |

### 节拍 2 — 教学：移动

| 属性 | 内容 |
|------|------|
| **时间** | 14s – 28s |
| **类型** | 游戏操作（教学） |
| **音乐** | 弦乐持续，加入轻微的打击节奏 |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 14 | 控制权交给玩家。英雄站在原地，前方 15 米处一把剑插在焦土中，剑身微光闪烁。 | 屏幕下方出现半透明提示：**「左摇杆 / WASD — 移动」**（持续 3 秒后自动消失） |
| 14–20 | 英雄向剑走去。如果玩家不走，6 秒后剑的光芒脉冲一次，作为视觉引导。 | 移动距离: 约 15m，预计耗时 4–6s。如果玩家 15 秒仍未走到剑前 → 触发文字提示：「走向那把剑……」 |
| 20–24 | 英雄走到剑前。剑身发出柔和金光。 | 屏幕提示：**「按 F / Y — 交互」** |
| 24–28 | 英雄拔剑。剑身光芒沿手臂流向全身——短暂的金色粒子特效。英雄的站姿从疲惫变为战斗姿态。 | 拔剑动画（约 2.5s）。剑入手后相机 FOV 微增（75 → 80），给玩家"我准备好了"的感觉。 |

**教学成功标准**: 玩家从站立到拔剑，全程不需要文字以外的帮助。

**边缘情况**:
- 玩家朝反方向走 → 相机轻轻拉回（不给硬边界），同时剑的光芒增强
- 玩家尝试攻击（未拔剑时） → 英雄做出空手推开的无效动作，剑的光芒脉冲引导
- 玩家 30 秒内仍未拔剑 → 直接触发系统辅助：镜头自动转向剑

### 节拍 3 — 教学：基础攻击

| 属性 | 内容 |
|------|------|
| **时间** | 28s – 48s |
| **类型** | 游戏操作（教学） |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 28 | 拔剑后，地面震颤。英雄前方 10 米处，3 个「深渊残影」（小型黑色人形怪）从地面裂缝中爬出。它们动作缓慢，无远程攻击。 | 提示：**「鼠标左键 / X — 普通攻击」**（持续 2s 后消失） |
| 28–35 | 玩家靠近并攻击。每个残影承受 **3 次普攻**即消散（`[PLACEHOLDER]` HP=30, 每刀伤害=12）。 | 连击：轻→轻→轻（三段动作），第三段为横扫，有轻微击退。音效：金属命中（sharp）+ 敌人消散（whoosh）。 |
| 35–40 | 三个残影清完后，地面再次震颤——更大范围，6 个残影分批出现：先 3 个（前方），3 秒后另 3 个（侧面）。 | 不给新提示，让玩家自己打。 |
| 40–48 | 清掉全部 6 个。最后一只消散时，短暂慢镜头（0.3s，0.2→1.0 倍速恢复）。 | 慢镜头是无声的奖励反馈——玩家会感觉到"这一刀有分量"。 |

**连击手感调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 调校方向 |
|------|--------|----------|
| 第一段前摇 | 0.15s | 太快 = 无重量感 / 太慢 = 迟钝 |
| 第二段前摇 | 0.25s | 需比第一段稍慢，建立节奏 |
| 第三段前摇 | 0.45s | 最慢，但伤害最高（×1.5） |
| 第三段伤害 | 18 | 确保能一刀补掉残血敌人 |
| 攻击硬直（敌人） | 0.3s | 每次命中让敌人短暂停顿 |
| 攻击后摇 | 0.2s | 闪避可取消后摇 |

**边缘情况**:
- 玩家全程不攻击 → 残影缓慢靠近但不造成伤害（教学保护），20s 后强制进入下一个节拍（残影自行消散，视为"击退"）
- 玩家站在原地挨打 → 残影攻击力=0（此节拍不掉血）

### 节拍 4 — 教学：技能

| 属性 | 内容 |
|------|------|
| **时间** | 48s – 70s |
| **类型** | 游戏操作（教学） |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 48 | 更大范围震颤。前方 20 米处，地面裂开——**8 个残影**同时爬出，呈扇形散开向英雄逼近。 | 屏幕提示：**「按 E / Y — 技能：辉光斩」**（持续显示，直到玩家使用）HUD 右下角技能图标亮起并脉冲。 |
| 48–58 | 玩家按技能键 → 英雄将剑刺入地面 → 以英雄为圆心，半径 6m 的金色冲击波扩散（AOE）。范围内残影全部直接消散。 | 技能动画约 1.5s（前摇 0.6s + 释放 0.9s）。释放期间英雄无敌。特效：地面裂纹 + 金色波环 + 残影灰飞烟灭的粒子。 |
| 58–62 | 光波消散，战场短暂安静。英雄喘一口气（微微躬身）。 | 无操作，纯喘息动画（1.5s）。让玩家消化"刚才很爽"的感受。 |
| 62–70 | 连续清了两波敌人后，英雄体力不支。屏幕边缘出现暗红色晕影（模拟虚弱感）。HUD 显示 HP 条首次出现，当前 HP=80%（`[PLACEHOLDER]`）。 | 无提示。HUD 淡入是"真正的战斗现在开始"的信号。 |

**技能调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| 技能冷却 | 8s | 防止连发，同时不觉得等太久 |
| AOE 范围 | 半径 6m | 刚好覆盖"感觉一大片"的最小范围 |
| AOE 伤害 | 50（秒杀杂兵） | 教学关数值不必严谨，要的是"爽" |
| 技能前摇 | 0.6s | 有蓄力感但不拖沓 |
| 释放无敌帧 | 全动画 | 避免"放大招被小兵打断"的挫败 |

**边缘情况**:
- 玩家持续不用技能 → 残影 15s 内靠近后真的造成伤害（每次 5 HP），给压迫感
- 玩家用普攻一个个打 → 也行，但效率极低。打完第 4 个后，剩余残影会加速，暗示"你需要技能"
- 如果玩家被残影打到 HP=0 → HP 锁在 1，触发紧急提示「按 E 使用技能！」

### 节拍 5 — 教学：闪避 + 强力敌人

| 属性 | 内容 |
|------|------|
| **时间** | 70s – 95s |
| **类型** | 游戏操作（教学） |

| 秒 | 画面 | 操作 / 教学 |
|----|------|-------------|
| 70 | 地面**剧烈**震颤。前方 20 米处，一只「深渊重甲兵」（约 3 倍英雄身高，持巨斧的大型敌人）从裂缝中爬出。地面震动传递到手柄。 | 提示：**「按 Shift / B — 闪避」**。大型敌人的头顶出现**红色预警光环**——这是全游戏统一的"可闪避攻击"标识。 |
| 72–78 | 重甲兵举起巨斧，**蓄力 2 秒**后砸下——地面出现红色圆形预警范围（半径 3m）。 | 玩家需要在蓄力完成前闪避出红圈。闪避成功 → 英雄翻滚至安全距离。闪避失败 → 受到 25 点伤害（约 25% HP），英雄被击退 5m。 |
| 78–85 | 重甲兵追上来，再次蓄力。这次蓄力更快（1.2s）。 | 第二次闪避练习。 |
| 85–90 | 重甲兵砸地后巨斧卡入地面 1.5s（硬直窗口）。此时重甲兵身上出现金色裂纹——提示"可以反击"。 | 不给文字提示，玩家自然理解"他动不了 = 我该打"。 |
| 90–95 | 玩家攻击硬直中的重甲兵 → 伤害 ×1.5。连击一套后重甲兵消散。 | 首次完整的"闪避→反击"循环完成。音效：巨斧砸地（低沉）+ 反击命中（清脆）。 |

**闪避调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| 闪避无敌帧 | 0.25s | 核心手感参数 |
| 闪避距离 | 5m | 足够避开半径 3m 的红圈 |
| 闪避冷却 | 0.5s（可连闪） | 允许连续闪避 |
| 敌蓄力时间（首次） | 2s | 给充足反应时间 |
| 敌蓄力时间（后续） | 1.2s | 加快节奏 |
| 敌硬直窗口 | 1.5s | 够打一套普攻 |

**边缘情况**:
- 玩家不闪避，硬吃伤害 → HP 降至 ~55%。不死，但屏幕晕影加重。此时重甲兵的下一次蓄力延长至 3s（游戏暗自降低难度）
- 被击中后 → 玩家获得 2s 的伤害免疫窗口，防止被连续击倒
- 玩家跑到远处（>30m） → 重甲兵缓慢追击，速度=英雄步行速度的 80%

### 节拍 7 — Boss 战：黑暗神 · 阶段一

| 属性 | 内容 |
|------|------|
| **时间** | 115s – 175s |
| **类型** | Boss 战（阶段一） |
| **音乐** | Boss 战 BGM：快速打击乐 + 弦乐短句循环 `[PLACEHOLDER]` |

#### Boss 机制 — 阶段一

| 参数 | 值 | 说明 |
|------|-----|------|
| HP | 300 `[PLACEHOLDER]` | 约 45–60s 可击破 |
| 攻击模式 | 2 种，轮流使用 | |
| 模式 A：暗影冲击 | 黑暗神从空中射出一束暗紫色能量柱，落点有 1.5s 红圈预警 | 半径 4m，伤害 30，冷却 8s |
| 模式 B：触手横扫 | 黑暗神挥舞触手横扫战场半场（左→右或右→左） | 伤害 25，需向触手方向闪避（穿过去）或后撤 |

#### Boss 行为循环

```
暗影冲击 → 等待 3s → 触手横扫 → 等待 3s → 暗影冲击 → ...
```
每次攻击后 Boss 有 **3s 硬直**，头部核心暴露——这是输出窗口。

#### 玩家操作节奏

| 阶段 | 动作 | 时长 |
|------|------|------|
| 躲技能 | 闪避暗影冲击 / 触手横扫 | ~2s |
| 输出窗口 | 接近 Boss 核心，普攻 + 技能 | ~3s（CD 好时放技能） |
| 拉开距离 | Boss 重新开始攻击前摇 | ~1s |

完整循环：约 6–7s。

**关键体验**: 玩家应该在这个阶段感到"我能读懂它的攻击了"——从紧张到有掌控感。

**数值调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| Boss HP | 300 | 单次循环伤害约 30，约 10 个循环击破 |
| 玩家普攻 DPS | 15/循环 | 3s 窗口 × 3 段 ≈ 15 |
| 玩家技能伤害 | 40/次 | CD 8s，每个循环放不出来——每 2 循环放一次 |
| Boss 暗影冲击伤害 | 30 (30% HP) | 有威胁但不致命 |
| Boss 横扫伤害 | 25 | 略低，因为是更难躲的范围技 |

**边缘情况**:
- 玩家 HP 降至 0 → 此 Boss 战 HP 锁在 1（这是教学关的最终 Boss 第一阶段，不在这让玩家死）
- 玩家长时间不攻击（>15s） → Boss 攻击频率降低，给玩家喘息空间
- HP 降至 50% → Boss 攻击间隔从 6s 缩短到 4s，给玩家"它在变强"的感觉

### 节拍 8 — Boss 战：黑暗神 · 阶段二（暴走）

| 属性 | 内容 |
|------|------|
| **时间** | 175s – 230s |
| **类型** | Boss 战（阶段二） |
| **音乐** | BGM 变化：加入急板弦乐 + 不和谐音 `[PLACEHOLDER]` |

#### 转阶段演出（175s–180s）

| 秒 | 画面 |
|----|------|
| 175 | HP 归零 → Boss 并未倒下，而是发出震耳欲聋的怒吼。屏幕震动 3s。 |
| 176–178 | Boss 的暗紫色身体边缘燃起黑色火焰。模型体积增大 20%。天空完全变暗。 |
| 178–180 | Boss HP 条重置——**但这次是黑色底 + 红色边框**（视觉信号：更危险）。新 HP=200。 |

#### 阶段二新增机制

| 新增攻击 | 描述 | 预警 | 伤害 |
|----------|------|------|------|
| **模式 C：暗影分裂** | Boss 分裂出 2 个小型残影（HP=20/个），从两侧夹击英雄 | 地面出现两个小紫圈 | 每个 10 |
| **模式 D：深渊之握** | 地面随机出现 3 个紫色漩涡，1s 后爆炸 | 紫色漩涡旋转加速 | 每个 20 |

阶段二的循环变为混沌模式：**3 种攻击随机排列**（不再是固定循环），每 3–5s 一次攻击。

#### 玩家体验设计

阶段二不能给玩家"规律的掌控感"——要的是**压迫**。角色 HP 在这个阶段应该降到 30–50%。

但因为是教学关，加入一个隐性帮助：
- 玩家 HP 降至 20% 以下时 → Boss 的下一次攻击必然有 0.5s 额外延迟
- 给玩家"我以为要死了……但居然躲开了"的体验

**暴走阶段调校** `[PLACEHOLDER]`:
| 参数 | 初始值 | 说明 |
|------|--------|------|
| Boss HP | 200 | 略少于阶段一，但容错更低 |
| 攻击间隔 | 3–5s（随机） | 比阶段一更紧凑 |
| 分裂残影 HP | 20 | AOE 技能可清 |
| 分裂残影伤害 | 10/次 | 不算高，但干扰节奏 |
| 漩涡爆炸范围 | 3m 半径 | 需要移动避开 |

**边缘情况**:
- 玩家在阶段二中真死了 → 回到阶段二开头（Boss HP=200），不从头开始。这是教学关的底线。
- 所有技能 CD 在重试时重置。

### 节拍 9 — 绝境与希望

| 属性 | 内容 |
|------|------|
| **时间** | 230s – 260s |
| **类型** | Boss 战（终段）+ 过场过渡 |

#### 终段（230s–240s）

| 秒 | 画面 | 玩法 |
|----|------|------|
| 230 | Boss HP 降至 0 → 第二次怒吼。但这回不一样——Boss 开始**蓄力最终一击**，全身黑色能量凝聚到核心。一个巨大的能量球在 Boss 头部形成。 | 屏幕中央提示：**「阻止它！」**（一个明确的紧迫目标） |
| 230–238 | 倒计时——能量球逐渐增大，屏幕边缘被暗紫色覆盖。玩家需要冲向 Boss 核心并攻击。 | 此阶段 Boss 不攻击，只蓄力。玩家全力输出。如果 8s 内打掉最后 50 HP → 触发下一节拍。如果时间到 → 能量球爆炸，直接进入节拍 10 的绝境。 |
| 238–240 | **无论玩家是否打掉 HP**——能量球在最后一刻爆炸。暗紫色冲击波扩散全场。英雄被击飞 10m，摔倒在地。HP 降至 1。 | 强制剧情事件。不可闪避。 |

**设计说明**: "无论输赢都会爆炸"是刻意设计的——告诉玩家：有些战斗不是靠力量能赢的。同时把剧情推向下一个转折。

#### 绝望时刻（240s–260s）— 过场

| 秒 | 画面 | 音频 |
|----|------|------|
| 240–244 | 英雄倒地，尝试撑起身体，但手臂颤抖——站不起来。剑脱手，插在 5 米外的焦土中。 | 呼吸声（粗重）+ 心跳声（缓慢、虚弱） |
| 244–250 | 镜头转向黑暗神。它在膨胀——能量失控——即将吞噬整个战场。英雄的瞳孔中倒映着扩散的暗紫色光芒。 | 低沉的嗡鸣渐强 |
| 250–255 | 英雄闭上眼睛。轻微微笑。——他接受了。 | 音乐完全停止 |
| 255–260 | 突然——**一道金色光芒从画面右侧射入**。一个少女的声音（轻柔、坚定）：*「还不能结束。」* | 一声清脆的铃音 + 金光入场 |

**情感锚点**: 这是整个游戏情感基调的起点——"你以为结束了，但她来了。"

## 技术需求

### 场景
- 古代战场：直径约 80m 的圆形竞技区域。材质：焦土 + 裂谷缝隙（发暗紫色光）。天空：动态 skybox，暗紫色能量风暴。
- 边界处理：战场边缘为悬崖 / 能量墙（透明的暗紫色屏障），碰到有视觉反馈（波纹），但不会把玩家弹回去——改成玩家自动转身。

### 角色
- **古代英雄**: 沿用了主角的基础骨骼。穿残破铠甲。武器：一把发光长剑。
- **女主**: 白色长袍，长发发光。仅过场出现，无需战斗动作。
- **深渊残影**: 小型敌人，基础 AI 跟随 + 近战。
- **深渊重甲兵**: 大型敌人，2 种 AI 行为（蓄力砸地 + 硬直）。
- **黑暗神**: 大型 Boss，场景绑定（不移动），多阶段 AI。

### 相机
- 探索/战斗：第三人称自由视角，默认距离 5m
- 拔剑瞬间：FOV 75→80
- 技能释放：FOV 短暂提升至 85（0.3s 缓动）
- 过场：完全镜头控制（引擎的 Sequencer / Timeline）

### HUD
- 序章期间：极简 HUD——仅教学提示，无 HP 条（节拍 4 才出现）
- 节拍 4 后：HP 条 + 技能图标 + Boss HP 条
- 第一章开始：完整 HUD
