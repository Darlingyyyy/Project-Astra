# 新手村 — 关卡设计

## 概述

**名称（暂定）**: 神树村  
**位置**: 神树森林边缘  
**作用**: 教学引导、世界观铺垫、建立玩家情感  
**预计游玩时长**: 30-60 分钟（主线）

## 各区域设计

### 村广场
- **用途**: 成人仪式举办地（游戏开场）、社交中心
- **NPC**: 村长、村民、同龄人
- **关键事件**: 成人仪式（触发主线）
- **可交互对象**: 公告板（支线任务）、神树雕像

### 主角家
- **用途**: 安全区、回忆触发点
- **可交互**: 床（休息/存盘）、镜子（查看状态）、日记（剧情线索）

### 酒馆
- **用途**: 情报收集、支线触发
- **NPC**: 酒馆老板、旅行商人、吟游诗人
- **功能**: 接收讨伐/采集支线任务

### 农田
- **用途**: 战斗教学区域（驱赶害兽）
- **敌人**: 小型野外生物（教学用）
- **教学**: 基础战斗操作

### 猎人小屋
- **用途**: 远程武器/游侠相关教学
- **NPC**: 老猎人
- **教学**: 瞄准、远程攻击基础

### 森林入口
- **用途**: 第一章终点，过渡到开放世界
- **事件**: 森林异常现象触发 → 主角决定调查
- **Boss**: 小 Boss（被深渊之力扭曲的生物）

---

## 任务设计

### 主线任务
1. 成人仪式（开场）
2. 村庄探索（自由）
3. 记忆碎片（触发）
4. 森林异变（高潮）
5. 启程（结束）

### 支线任务（Demo 目标 5-8 个）
- 采集药草（农田区）
- 驱赶害兽（农田区，战斗教学）
- 寻找走失的羊（森林边缘）
- 给猎人送信
- 酒馆的委托（讨伐小怪）
- 寻找丢失的护身符（村庄搜索）
- 帮村民修理工具（采集+交付）
- 老猎人的试炼（远程教学）

---

## 教学节奏

| 顺序 | 教学内容 | 方式 |
|------|----------|------|
| 0 | 移动 + 视角 | 序章梦境（自动引导） |
| 1 | 战斗基础 | 农田驱赶害兽 |
| 2 | 对话 + 任务 | 与村民互动 |
| 3 | 远程攻击 | 猎人小屋（可选） |
| 4 | 物品收集 | 支线任务 |
| 5 | Boss 战 | 森林入口 |
