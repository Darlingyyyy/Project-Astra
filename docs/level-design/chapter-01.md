# 第一章：成人仪式 — 逐秒节拍设计

> **版本**: v1.0 · 2026-06-23
> **状态**: 设计阶段 — 待原型验证
> **预计时长**: 约 45-60 分钟
> **设计模式**: 单人（主角 Lv1）→ 村庄自由探索
> **设计目标**: 建立村庄归属感 + 梦与现实对照 + 成人仪式触发记忆觉醒 + 首次真实战斗 + 启程动机

---

## 设计目标

| # | 目标 | 验收标准 |
|---|------|----------|
| 1 | 从噩梦中醒来的情感残留持续到第一章 | 测试者推窗后停顿 2s 以上 |
| 2 | 村庄让人产生「这是我的家」的感觉 | 测试者自发探索 3 个以上区域 |
| 3 | 成人仪式感庄重 | 测试者在仪式期间不按跳过 |
| 4 | 记忆碎片触发后玩家主动想了解更多 | 测试者问「那个女孩是谁」 |
| 5 | 森林异变制造不安 | 测试者犹豫是否进入森林 |
| 6 | 首次真实战斗体现 Lv1 的脆弱 | 测试者至少使用一次闪避 |
| 7 | 启程决定有分量 | 测试者离开前回头看一眼村庄 |

---

## 第一章角色状态

| 角色 | 状态 |
|------|------|
| 主角 | Lv1，村民身份，刚参加成人仪式。无职业。手持训练木剑。**无任何技能**（仅普攻 + 闪避）。不知道自己是转世英雄。 |
| 女主 | **不出现**。仅以记忆碎片形式短暂闪现（玩家知道她存在，主角不知道） |
| 大法师 | **不出现**。第一章无他的戏份 |
| NPC | 村长、铁匠学徒、酒馆老板、老猎人、童年好友、村民若干 |

> **关键设计决策**：第一章不给任何队友。主角是孤独的。这建立后续「旅途开始→结识伙伴」的回报感。梦中的三人小队是已经失去的东西——第一章的全部体验是「少了什么」。

## 节拍 0 — 醒来：梦与现实之间

| 属性 | 内容 |
|------|------|
| **时间** | 0s – 45s |
| **类型** | 过场动画 → 控制权交接 |
| **音乐** | 无声 → 村庄清晨环境音（鸟鸣、远处铁匠锤声）→ 轻柔钢琴起 |

| 秒 | 画面 | 音频 |
|----|------|------|
| 0–3 | **接序章 Beat 9 最后一帧**：主角推窗，窗外神树村蓝天。章节标题「第一章 · 成人仪式」淡出（约 3s）。 | 序章 BGM 余韵 → 村庄环境音渐入 |
| 3–8 | 镜头从窗外缓缓拉回室内。屋内：木床（被褥散乱）、一张简陋木桌、角落里一个旧箱子。墙上挂着一把训练木剑。 | 环境音：公鸡啼鸣（稍远）、木地板轻微吱呀 |
| 8–12 | 主角的手从窗框上滑下。他仍站在那里——不是看风景，是**在回想**。镜头给他的脸一个中景：困惑、不安、嘴角微张想说什么却说不出。 | 心跳声（1拍/秒，约 4 拍）——与序章 Beat 0 主角趴在地上时的心跳同频，暗示梦境残留 |
| 12–18 | 主角低头看自己的手——手是干净的，没有伤痕，没有金色光芒。他握拳再松开——确认这是真实的。 | 心跳结束。呼吸稳定。 |
| 18–22 | 屏幕下方出现半透明提示：**「按 W A S D — 移动」**（3s 后自动消失）。 | 钢琴单音——一个疑问式的、悬在半空的音符 |
| 22–45 | **控制权交给玩家**。主角在屋内，可以探索：床、桌子、木剑、旧箱子、门口。门未上锁，可自由离开。 | 村庄环境音持续 |

**屋内可交互对象**：

| 对象 | 交互方式 | 内容 |
|------|----------|------|
| 床 | 按 E | 「昨晚又做梦了……但这次不一样，太清晰了。」 |
| 镜子 | 按 E | 主角首次看清自己的脸。镜头短暂拉近（面部特写 2s）。玩家第一次看到「自己」。 |
| 日记 | 按 E | 翻开日记本——最近几页写满潦草涂鸦和重复的句子：「又是那个梦」「有人在叫我」「金色的光」。最后一页只有一句话：「今天成人仪式。希望今晚能睡个好觉。」 |
| 训练木剑 | 按 E | 主角拿起木剑，掂了掂（动画），放回。提示：**「鼠标左键 — 普攻」**。这是第一章唯一一次给出的战斗提示——序章的战斗教学不继承，因为那是「前世英雄」的技能，主角现在是零基础。 |
| 旧箱子 | 按 E | 里面是儿时的东西：一颗光滑的石头、一个坏掉的弹弓、母亲的旧围巾。主角摸了摸围巾，放回去。 |
| 门 | 移动触发 | 推开门，进入村庄。如果 30s 内未出门 → 屋外传来喊声：「快出来！成人仪式快开始了！」 |

**此节拍的情绪曲线**：
```
序章残留的恍惚 → 环顾四周确认这是真实的 → 
发现日记/旧物的「自己的生活」→ 听到喊声被叫回现实
```

**伏笔植入**：
| 伏笔 | 位置 | 回响 |
|------|------|------|
| 日记中的「有人在叫我」 | 日记交互 | 第二章起：那是女主的呼唤跨越轮回 |
| 旧箱子里的母亲围巾 | 箱子交互 | 第三章：父母的过去 |
| 木剑「训练用」 | 拿起木剑 | 第一章 Beat 6：这是主角第一次真正用剑 |

## 节拍 2 — 成人仪式：神树的触碰

| 属性 | 内容 |
|------|------|
| **时间** | 8min – 14min（触发条件：进入广场后 >5min 或与村长对话选择「我准备好了」） |
| **类型** | 过场动画 + 记忆碎片 |
| **音乐** | 仪式 BGM：低音弦乐 + 人声哼唱（无词），庄严但不压迫 [PLACEHOLDER] |

### 仪式流程

| 秒 | 画面 | 音频 |
|----|------|------|
| 0–10 | 主角走到广场中央，与其他几位同龄人并排站立。广场周围站满村民。村长站在神树分枝前，手掌按在树干上。阳光透过树冠洒在仪式区域。 | 人声哼唱渐入 + 轻柔风铃 |
| 10–20 | 村长开口：「神树见证。今日，你们将触摸神树——它会看见你的过去，也会看见你的可能。无论看到什么，记住：**你是被选中的。**」 | 村长的声音苍老但清晰，每个字都有回声（1次，短混响） |
| 20–30 | 第一位同龄人上前，手放上神树。树干发光（暖金色），他的表情微笑：「我看到了爷爷的铁匠铺……还有一把很厉害的剑。」村民轻声欢呼。 | 暖光音效（短促上扬）→ 轻快的弦乐 |
| 30–38 | 第二位同龄人上前。光较弱——她皱眉：「我……什么都没看到。」村长拍拍她：「不急，有的人要很久以后才会明白。」 | 短暂死寂 → 村长温暖的低音 |
| 38–50 | 轮到主角。他走向神树。镜头从他的背后跟拍——他的脚步在树干前停下。他深吸一口气，伸手。 | 深呼吸声（和序章 Beat 0 站起来的呼吸同频）→ 所有声音骤停 |
| 50–55 | 手触碰树干的瞬间——**金光自手掌向外猛烈扩散**，比第一个同龄人的光强烈数倍。树干上的手印痕全部亮起，如同时共鸣。主角的身体僵住——不是被控制，是**被信息淹没**。 | 沉重的共鸣音（类似寺庙钟声，但更低沉）→ 持续嗡鸣 |
| 55–65 | **记忆碎片 1**：女主的背影，白色长袍，长发在风中飘动。她穿过的不是村庄，是那远古战场——焦土、裂缝、暗紫色的天空。她转过头——画面还没看清她的脸就中断。 | 风声 + 心跳（主角的，快速的） |
| 65–72 | 主角猛地松手，后退一步，大口喘气。周围所有人看着他——有些在窃窃私语。村长的表情最复杂：惊讶、担忧、还有一种「果然如此」的了然。 | 心跳持续 → 群众低语杂音 |
| 72–80 | 村长走近，压低声音，只有主角能听到：「**你看到了不同的东西。**仪式结束后，来找我。」然后提高音量，对所有人：「今天的仪式完成了。欢迎你们——成为神树村的大人。」 | 村长低语（近距离，无混响）→ 宣布时人群欢呼渐入 |

**此节拍的情绪曲线**：
```
期待(排队) → 观察(看别人) → 紧张(上前) → 冲击(金光爆发) → 
困惑(女主背影) → 恐惧(喘气) → 不安(村长的话)
```

**关键设计点**：
- 这是玩家**第一次在「现实」中看到女主的形象**——之前只在「前世梦境」中见过她。给的是背影——保持距离感。
- 村长的私语是伏笔——他知道一些事情。
- 主角此时只是困惑和不安，完全没有「我要去找她」的意识。这留给第一章后半段的记忆碎片来建立。

## 节拍 3 — 仪式之后：记忆的涟漪

| 属性 | 内容 |
|------|------|
| **时间** | 14min – 25min |
| **类型** | 自由探索 + 触发式记忆碎片 |
| **音乐** | 村庄 BGM 回归，但比 Beat 1 更安静——仿佛连环境都知道有什么在酝酿 [PLACEHOLDER] |

### 可触发的记忆碎片

> 设计原则：这些碎片自动触发，不需要玩家交互。主角只是走在正确的位置——记忆就会撞上他。每个碎片长 2-4s，没有解释，没有前因后果。累积效应是不安。

| 编号 | 触发位置 | 触发条件 | 画面 | 声音 |
|------|----------|----------|------|------|
| MF-1 | 走向铁匠铺（与童年好友会合） | 经过广场 → 铁匠铺之间的小路 | 女主的侧脸——她在笑，嘴唇翕动似乎在说什么。画面有金色的雾。 | 隐约的女生低语（听不清内容） |
| MF-2 | 酒馆门口 | 与旅行商人对话后离开酒馆 | 女主的双手——正在结印（序章中的封印术手势）。暗紫色纹路从手腕向指尖蔓延。 | 沉重心跳 2 拍 |
| MF-3 | 农田的稻草人旁 | 在农田练习普攻 ≥5 次 | 一把发光的长剑插在焦土中——正是序章前世英雄的剑。 | 金属颤音（同序章 Beat 0 的剑音） |
| MF-4 | 自家门口 | 返回家中 | 大法师的背影——他转过头似乎要说什么，但画面中断。 | 大法师的呼吸声（粗重，接续序章 Beat 8 他跪地的状态） |

> **MF ≠ Memory Fragment。这些不是前世记忆的重播——它们是**断裂的、碎片化的余音**。主角无法理解，玩家能感受到「那些梦中的人还活着／曾经活过」。

### 与村长对话（主线触发点）

触发条件：任一记忆碎片被触发后，走向广场村长处。

| 对话 | 主角选项 |
|------|----------|
| 村长：「你看到了什么？」 | |
| | ① 「一个女孩……穿着白袍。」 |
| | ② 「我不确定……太混乱了。」 |
| | ③ （沉默） |
| 村长（无论选什么）：「……果然。」他沉默片刻：「神树从不给无关的东西。如果它让你看到这些——说明这些与你有关。」 | |
| 村长：「我给你一个人的消息。老猎人说他看到森林深处有奇怪的光——和神树同样的光。如果你想弄清楚，去问他。」 | |
| 村长最后一句：「**但这些事——你自己决定。没有人能替一个刚成年的人做选择。**」 | |

| 奖励 | 少量金币 + 童年好友好感度 |

| 项目 | 内容 |
|------|------|
| 触发 | 酒馆老板 |

| 叙事价值 | 了解村庄的资源循环 |

### 支线 3：驱赶害兽 ★ 战斗教学

| 项目 | 内容 |
|------|------|
| 触发 | 猎人小屋，与老猎人对话 |
| 目标 | 进入农田，驱赶 3 只「影鼠」（被深渊之力轻微污染的小型生物） |
| 敌人 | 影鼠 ×3，每只 HP ~15 [PLACEHOLDER]。攻击模式：近身撕咬（前摇 0.8s，伤害 3-5） |
| 教学 | **闪避**+**普攻连段**。无提示——让玩家通过战斗自然感受 Lv1 的脆弱 |
| 奖励 | 训练木剑 → 猎人的旧短剑（ATK +5） + 老猎人的信任 |
| 设计要点 | 序章中玩家扮演的是「满级前世英雄」——技能华丽、AOE清屏。到了第一章 Lv1——只有普攻、只有闪避、打三只老鼠都要认真躲。**这个落差本身就是叙事。** |

**影鼠战斗设计**：

```
敌人配置：农田区域，3 只影鼠同时存在，间隔 4-6m
AI：轮流上前攻击（不群殴——给 Lv1 玩家操作空间）
每只影鼠被击杀后，尸体会化为暗紫色粒子消散（和序章残影同样特效——伏笔：深渊污染已渗透到村庄外围）

如果玩家 HP 归零 → 无死亡惩罚，在自家床上醒来，旁白：「还好只是擦伤。」
老猎人会说：「再来一次。这次看准了再躲。」
```

## 节拍 6 — 森林深处：第一次真正的战斗

| 属性 | 内容 |
|------|------|
| **时间** | 48min – 56min |
| **类型** | 探索 + 战斗 |
| **音乐** | 森林 BGM：低沉的环境音，偶尔听到远处野兽的低吼。无旋律——等待战斗触发 [PLACEHOLDER] |

### 森林探索

森林场景与序章的远古战场形成强烈对比：序章是开阔的 80m 竞技场、天空是暗紫色风暴——而这里是**高大的树木、斑驳的暮光、狭窄的小径**。主角独自一人，没有队友。

| 位置 | 内容 |
|------|------|
| 小径 | 沿途有倒下的树干、发光蘑菇（可采集）、被撕裂的树皮（动物逃跑的痕迹） |
| 空地 | 一块约 10m 半径的空地，中央是一棵较小的神树分枝——树干上的手印全是**黑色**的。走近触发主角独白：「这和广场上的树……一样。但为什么是黑的？」 |
| 深处的光 | 空地尽头，金色的光从灌木丛后透出。靠近触发战斗。 |

### 战斗：被污染的森林守护者

| 参数 | 值 |
|------|-----|
| 名称 | 腐化的森林守护者（暂定名） |
| 类型 | 中型 Boss |
| HP | 80 [PLACEHOLDER] |
| 攻击模式 | 3 种 |

| 攻击 | 描述 | 预警 | 伤害 |
|------|------|------|------|
| 藤蔓抽击 | 前肢化为藤蔓横扫前方 4m | 蓄力 1.2s，藤蔓表面泛起暗紫色 | 15 [PLACEHOLDER] |
| 根须穿刺 | 地面出现 3 条根须，沿直线穿刺 | 地面暗紫色裂纹 1s | 10/条 |
| 咆哮震击 | 自身周围 5m 范围震击 | 身体膨胀 0.8s | 8 [PLACEHOLDER] |

每次攻击后有 2s 硬直——输出窗口。

**Boss 设计要点**：
- 这不是序章 450 HP 的黑暗神——这是 **80 HP** 的被污染生物。Lv1 的主角普攻每次 1（不包含装备加成），需要约 30-40 次命中。
- 主角必须闪避、找硬直窗口输出、不能硬扛。
- Boss 的暗紫色藤蔓与序章黑暗神的触手是**同色系**——视觉上暗示这是深渊污染的外溢。
- Boss 被击败时，它体内的暗紫色能量被抽离、汇入森林深处的金光方向——污染物被「吸走了」。

**边缘情况**：
- 主角 HP 归零 → 战斗结束，黑屏。老猎人的声音：「我听到动静了——」然后主角在老猎人小屋醒来。可以重新挑战。Boss HP 重置。
- 使用骨笛 → 老猎人射一箭（伤害 ~25 [PLACEHOLDER]）+ Boss 短暂眩晕 3s。仅限一次。

## 节拍 7 — 光的方向：决心

| **类型** | 过场动画 + 章节结束 |
| **音乐** | 战斗结束后的寂静 → 轻柔钢琴起（与序章 Beat 9 同旋律但更安静） |

| 秒 | 画面 | 音频 |
|----|------|------|
| 0–5 | Boss 消散——暗紫色粒子随风飘向森林深处，被金色光束吸收。主角单膝跪地，大口喘气。这是他第一次用真剑战斗——手在抖。 | 喘气 + Boss 消散音效（暗紫粒子沙沙声） |

| 20–25 | 回到现实。主角站在原地，手不自觉地按在胸口——那个位置，正是序章中感受到女主消散的地方。他现在明白了：**那不是梦。** | 心跳（缓慢而坚定） |
| 25–35 | 主角转身，最后一次看向身后——透过树冠，能看到远处村庄的炊烟。那是他 18 年来唯一的家。他看了 3 秒——然后转回身，面向金光的方向。 | 村庄环境音（极远处）→ 被风吹散 |
| 35–45 | 主角迈出一步——踏出森林的「安全区」边界。镜头从背后缓缓拉起，拉高——主角的身影越来越小，他走向的光越来越亮。 | 女主主题旋律进入完整编制（管弦乐） |
| 45–50 | 屏幕渐黑。中央浮现： | |
|  | **第二章** | |
|  | *旅途开始* | |
|  | 章节标题持续 3s 后淡出。 | 管弦乐最后一个和弦 → 安静 |

**此节拍的情绪曲线**：
```
喘息(刚战斗完) → 好奇(走向光) → 震撼(看到她的脸) → 
领悟(那不是梦) → 回望(告别童年) → 转身(决定) → 迈步(启程)
```

**叙事设计要点**：
- 第一章女主的脸只让玩家看到**一次**——而且没有声音。第二章她才会真正出场。第一章的作用是建立「想看更多」的渴望。
- 「那不是梦」——这是主角从「被动接受」转向「主动追寻」的关键心理转换。但它不通过台词说出口，而是通过他按胸口的动作和最后的眼神来传达。
- 回望村庄的 3 秒是给玩家的情感空间——让他们和主角一起告别。
- 森林小路通往第二章的开放世界。第一章没有打开世界地图——玩家不知道外面有什么。第二章展开。

- 黄昏后 NPC 自动回到室内

- 硬直判定：每次攻击后 2s
- 击败后暗紫色粒子汇入金光方向
