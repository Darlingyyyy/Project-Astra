# 美术风格指南 — Project Astra

> **版本**: v0.2  
> **引擎**: Unity 2022.3 LTS + URP  
> **渲染**: Cel Shading（卡通渲染）  
> **最后更新**: 2026-06-02

---

## 已确定方向

### 参考作品
- **Genshin Impact** — 明亮、动画风格、高饱和度、Cel Shading
- 探索阶段最核心参考

### 核心设定

| 维度 | 方向 |
|------|------|
| 渲染管线 | URP + 自定义 Cel Shading |
| 角色风格 | 动画风格（非写实），类似原神比例 |
| 环境 | 明亮开阔，生机盎然 |
| 色彩 | 高饱和度·温暖色调为主·深渊区域冷色调 |
| 后处理 | Bloom · 色调映射 · 景深 |
| UI | 原神风 HUD — 左上队伍·右下技能·右上小地图 |

### 区域美术关键词

| 区域 | 关键词 |
|------|--------|
| 神树村 | 绿意·阳光穿过树叶·温暖泥土色 · 木屋 |
| 神树森林 | 巨型古树·荧光植被·神秘而温柔 |
| 远古战场 | 焦土·残破石柱·暗红天光·压抑 |
| 深渊 | 冷色调·扭曲几何·暗紫与深蓝 |
