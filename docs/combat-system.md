# 战斗系统设计

## 概述

第三人称即时动作战斗，三人小队制。玩家控制一名角色，AI 控制另外两名。战斗中可随时切换操控角色。

---

## 队伍结构

```
┌─────────────────────────────────────┐
│           三人小队                    │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ │
│  │ 操控角色 │ │ AI 角色 │ │ AI 角色 │ │
│  │ (玩家)   │ │ (伙伴1) │ │ (伙伴2) │ │
│  └─────────┘ └─────────┘ └─────────┘ │
│          ↕ 即时切换 ↕                  │
└─────────────────────────────────────┘
```

### 切换机制
- 一键切换操控角色（冷却时间待定 `[PLACEHOLDER]`）
- 切换时触发入场技能效果（如：切换至战士 → 自动嘲讽周围敌人）
- 切换动作带有短暂无敌帧

---

## AI 行为

### AI 角色基础行为
- **跟随**: 默认保持与玩家一定距离
- **自动攻击**: 优先攻击玩家锁定目标
- **自动闪避**: 面对可预判攻击时尝试闪避
- **技能使用**: 根据预设策略使用技能（可配置倾向：进攻型/防御型/辅助型）

### AI 策略配置 `[PLACEHOLDER]`
- 进攻型：优先使用高伤害技能
- 防御型：优先格挡/闪避，保留技能应对危机
- 辅助型：优先维持增益和治疗

## 连携系统

连携是战斗深度的核心：两名角色的特定技能/状态组合触发额外效果。

### 已设计连携

| 组合 | 触发效果 | 伤害类型 |
|------|----------|----------|
| 冰冻 + 重击 | **碎冰爆发** — 大范围物理伤害 + 破甲 | 物理 |
| 燃烧 + 箭矢 | **爆燃** — 高额火伤 + 持续灼烧 | 火元素 |
| 圣光增益 + 狂暴 | **神圣狂怒** — 攻击力大幅提升 + 吸血 | 光/物理 |

### 连携设计原则
- 每次连携触发应有**明显的视听反馈**（镜头震动、特效、音效）
- 连携应有冷却，防止无限触发
- 鼓励玩家尝试不同角色组合
