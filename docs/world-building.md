# 世界观设定 — 艾尔德拉大陆

## 世界概述

艾尔德拉大陆是一个由三种本源力量维持平衡的世界。这三种力量如同世界的三根支柱，任何一根的动摇都将引发连锁崩塌。

---

## 三种本源力量

### 神树之力
- **本质**: 生命、生长、永恒的秩序
- **象征**: 位于大陆中心的神树，相传是世界生命的源头
- **影响**: 赋予万物生机，维持四季轮转与生态平衡

### 秩序之力
- **本质**: 法则、稳定、文明的基石
- **象征**: 散布大陆各处的古代遗迹与能量节点
- **影响**: 维持物理法则与世界结构的稳定

### 深渊之力
- **本质**: 混沌、毁灭、原始的本能
- **象征**: 地底深渊，黑暗能量的源头
- **影响**: 侵蚀秩序，扭曲生命，但也是创造与毁灭循环中不可或缺的一环

---

## 历史纪元

### 远古时代 — 封印战争
1. 深渊之力凝聚，诞生了黑暗神
2. 黑暗神试图吞噬整个世界，将一切归于混沌
3. 古代英雄们集结，联合三大力量对抗黑暗神
4. 一名少女发现自身拥有特殊的封印能力，她以自己为容器，将黑暗神封印于体内
5. 封印完成，世界进入新的时代

### 新纪元 — 脆弱和平
- 黑暗神的威胁消除，文明开始重建
- 但封印从未真正稳定——黑暗神的力量仍在缓慢渗透
- 关于那场战争的记忆逐渐化为传说，最终被遗忘

### 当代 — 轮回的预兆
- 封印开始出现裂痕
- 深渊之力在世界各地引发异常现象
- 拥有前世记忆的人开始出现
- 远古的英雄即将转世归来……
