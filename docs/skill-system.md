# 技能系统设计 v3.0 — Project Astra

> **版本**: v3.0 · 2026-06-03  
> **设计方案**: 自由加点技能树（等级驱动·阶段解锁）  
> **职业数**: 6  
> **核心原则**: 每 10 级一个阶段解锁新技能池，技能点自由分配——新技能解锁或旧技能专精，玩家自主构筑

---

## 设计框架总览

```
技能系统由两层构成：

┌──────────────────────────────────────────────────┐
│  第 1 层 · 职业分支技能（8 主动 + 8 被动）          │
│  四阶段解锁·自由加点·同职业共享技能池               │
├──────────────────────────────────────────────────┤
│  第 2 层 · 角色专属技能（专属被动 + 专属技 + 大招）  │
│  角色绑定·开局解锁·定义角色唯一性                   │
└──────────────────────────────────────────────────┘

等级驱动：
  Lv 1-10  → Tier 1 解锁（2 主动 + 2 被动）· 基础攻防
  Lv 10-20 → Tier 2 解锁（2 主动 + 2 被动）· 续航机动
  Lv 20-30 → Tier 3 解锁（2 主动 + 2 被动）· 机制玩法
  Lv 30-40 → Tier 4 解锁（4 技能·质变阶）· 核心灵魂

技能点规则：
  每升 1 级 → +1 技能点
  解锁新技能 → 花费 1 点（解锁 = 1 级）
  升级已有技能 → 花费 1 点 / 级
  
  等级上限：
    Tier 1-3 技能 → 最高 15 级（解锁 1 级 + 再升 14 级）
    Tier 4 技能   → 最高 5 级（解锁 1 级 + 再升 4 级）
  
  满级 40 级 = 39 技能点（按二周目扩展可至 110 点）

每职业技能池：8 主动 + 8 被动 = 16 技能
技能栏位：4 主动槽（QERF）+ 专属被动（固定）+ 专属技 + 大招
```

### 设计约束

- Tier 1-2：基础技能，简单直接，教玩家理解职业
- Tier 3：机制技能，改变玩法方式，引入职业特色
- Tier 4：核心质变，定义终极方向，灵魂所在
- 同 Tier 内技能有约 20% 的轻量联动（非强制，鼓励组合）
- 洗点机制：可在安全区域（神树村/营地）免费重置所有技能点

## 七、主角专属技能（前世记忆）

> 主角在序章中体验过前世英雄的记忆后，从 Lv 1 起自动拥有以下专属技能。  
> 这些技能**跨职业生效**，无论主角选择圣骑士/狂战士/法师/祭祀/刺客/猎人，均可使用。  
> 设计原则：与具体职业无关，绑定「灵魂」而非「身体」。

### 专属主动技：轮回之触

| 效果 |
|------|
| 触碰敌人的灵魂本质，造成 200% [主属性] 伤害 |
| 施加「记忆烙印」标记，持续 8s |
| 被烙印的敌人受到的所有伤害 +15% |
| CD 18s |
| 如果目标是 Boss，烙印期间主角每秒回复 2% HP |

> **设计意图**: 一个短 CD 的通用增伤挂件。无论什么职业，先手挂上烙印再开爆发都是最优解。Boss 战附带回血让主角在面对强敌时有叙事感——「记忆让我坚韧」。

### 专属被动技：不灭的记忆

| 效果 |
|------|
| HP 低于 20% 时自动触发「记忆闪回」 |
| 2s 内无敌 + 5s 内伤害 +30% |
| 闪回期间屏幕边缘泛起金色光晕（前世记忆碎片视觉特效） |
| CD 120s |

> **设计意图**: 绝境被动——不是让你无敌爆发 10s，而是给 2s 无敌让你喘口气 + 5s 伤害窗口让你反打。时间窗口紧凑，需要操作。叙事上：主角的灵魂「记得」如何活下来。

### 专属大招：觉醒 · 英雄之魂

| 效果 |
|------|
| 短暂唤醒前世英雄的力量，持续 12s |
| 觉醒期间效果： |
|   - 所有职业主动技 CD 减半 |
|   - 所有伤害附带额外 30% 神圣属性伤害 |
|   - 移动速度 +20% |
|   - 角色身上浮现金色半透明前世英雄虚影 |
| CD 180s |

> **设计意图**: 不替代职业大招，而是放大多元——不管你是圣骑士还是刺客，觉醒让你暂时突破职业上限。视觉上能看到前世英雄的虚影叠加在自己身上——叙事的视觉化。

### 关于「单独设计几版」的说明

以上为通用版本，适合初期开发。若后续希望每职业拥有不同风味的主角专属技，可以按以下方向扩展：

|------|-------------|-------------|---------|

| 法师 | 轮回之触 AoE 溅射 | 闪回时魔力回满 | 觉醒期间所有法术免费 |
| 祭祀 | 轮回之触改为治疗烙印（队友） | 闪回时全队回复 30% HP | 觉醒期间 BUFF 效果翻倍 |
