# 技能系统设计 v3.0 — Project Astra

> **版本**: v3.0 · 2026-06-03  
> **设计方案**: 自由加点技能树（等级驱动·阶段解锁）  
> **职业数**: 6  
> **核心原则**: 每 10 级一个阶段解锁新技能池，技能点自由分配——新技能解锁或旧技能专精，玩家自主构筑

---

## 设计框架总览

```
技能系统由两层构成：

┌──────────────────────────────────────────────────┐
│  第 1 层 · 职业分支技能（8 主动 + 8 被动）          │
│  四阶段解锁·自由加点·同职业共享技能池               │
├──────────────────────────────────────────────────┤
│  第 2 层 · 角色专属技能（专属被动 + 专属技 + 大招）  │
│  角色绑定·开局解锁·定义角色唯一性                   │
└──────────────────────────────────────────────────┘

等级驱动：
  Lv 1-10  → Tier 1 解锁（2 主动 + 2 被动）· 基础攻防
  Lv 10-20 → Tier 2 解锁（2 主动 + 2 被动）· 续航机动
  Lv 20-30 → Tier 3 解锁（2 主动 + 2 被动）· 机制玩法
  Lv 30-40 → Tier 4 解锁（4 技能·质变阶）· 核心灵魂

技能点规则：
  每升 1 级 → +1 技能点
  解锁新技能 → 花费 1 点（解锁 = 1 级）
  升级已有技能 → 花费 1 点 / 级
  
  等级上限：
    Tier 1-3 技能 → 最高 15 级（解锁 1 级 + 再升 14 级）
    Tier 4 技能   → 最高 5 级（解锁 1 级 + 再升 4 级）
  
  满级 40 级 = 39 技能点（按二周目扩展可至 110 点）

每职业技能池：8 主动 + 8 被动 = 16 技能
技能栏位：4 主动槽（QERF）+ 专属被动（固定）+ 专属技 + 大招
```

### 设计约束

- Tier 1-2：基础技能，简单直接，教玩家理解职业
- Tier 3：机制技能，改变玩法方式，引入职业特色
- Tier 4：核心质变，定义终极方向，灵魂所在
- 同 Tier 内技能有约 20% 的轻量联动（非强制，鼓励组合）
- 洗点机制：可在安全区域（神树村/营地）免费重置所有技能点

### 设计说明

**纯 CD 制的刺客**：旧版 v2.0 的「暗影点数」已被移除。刺客的隐身→暴击→处决循环完全由操作和 CD 驱动。核心博弈是"什么时候现身？"——现身太早打不出隐身加成，现身太晚队友的血线撑不住。

**处决机制**：Tier 4 被动「处决」是全游戏唯一的低血即死机制。配合死亡标记的自动处决，刺客在斩杀阶段是绝对的主宰。但对 Boss 无效，确保 Boss 战不会因为被动而失去挑战性。

### 设计说明

**全游戏最自由的职业**：猎人的四分支（强射/速射 → 陷阱/宠物 → 标记/机动 → 独狼/兽群）可以任意混搭——想玩用陷阱锁敌然后用连射收割的陷阱速射流？想做带着猎鹰风筝全场同时翻滚自保的兽王风筝流？想做站桩蓄力一击秒 Boss 的独狼狙击手？全在技能点分配里。猎人是 v3.0 自由加点框架的最佳体现——没有"标准建法"。

**纯 CD 制**：旧版 v2.0 的「专注值（消耗型资源）」已被移除。现在的「专注」是固有被动——站定叠伤、移动惩罚，不需要管理资源条。猎人真正的资源是**站位**和**距离**。

**四分支混搭示例**：
- **独狼狙击流**：强力射击 + 鹰眼 + 稳定瞄准 → 猎人印记 + 弱点暴露 → 致命一击 + 独狼。站定→蓄力→一箭秒

- **陷阱控制流**：连射 + 鹰眼 → 捕兽夹 + 陷阱大师 → 猎人印记 + 弱点暴露 → 致命一击 + 独狼。陷阱锁敌→标记→蓄力收割

|------|
| 挥出一道 15m 宽的弧形神圣剑气，穿透所有敌人 |
| 造成 300% 神圣伤害，无视 50% 防御 |
| 命中敌人附加「辉光烙印」3s：减速 50% + 受到神圣伤害 +25% |

> 已在序章设计文档（prologue.md Beat 3）中确立。

### 专属被动技：英雄之魂

| 效果 |
|------|
| 当前 HP 越低，造成伤害越高 |
| HP 100%–51%: 伤害 +10% |
| HP 50%–21%: 伤害 +25% |
| HP 20% 以下: 伤害 +50% |
| 额外效果：任何导致死亡的伤害会先保留 1 HP，触发一次 1s 无敌（每场战斗 1 次） |

> **设计意图**: 为什么序章英雄越打越强？因为他的故事就是以命相搏。最后那「1 HP 不死」是给玩家在绝境中反打的剧本空间。

### 专属大招：天启

| 效果 |
|------|
| 以英雄为中心爆发圣光冲击波，覆盖 20m |
| 第一段：全屏 500% 神圣伤害 |
| 第二段：所有被命中的敌人眩晕 3s |
| 第三段：英雄自身回复 50% 最大 HP |
| CD 150s |

> **设计意图**: 序章 Boss 战结尾技能——当黑暗神以为赢了，英雄开天启反击。三段效果（伤害→控制→回血）形成完整的叙事节奏：反击→喘息→新生。
