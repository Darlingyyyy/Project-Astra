## 主角

| 属性 | 内容 |
|------|------|
| **身份** | 神树森林边缘村庄的普通村民 |
| **实际身份** | 古代英雄转世 |
| **年龄** | 18岁（成人仪式） |
| **特征** | 不断梦见前世记忆碎片 |

### 角色弧线
1. **起点**: 普通村民，对世界一无所知
2. **觉醒**: 记忆碎片逐渐拼合，发现自己与远古战争的联系
3. **使命**: 从「被动接受命运」到「主动为所爱之人而战」
4. **终点**: 完成真正的英雄使命——不只是击败黑暗神，而是修复世界

参见 `class-system.md`

## 女主

| 属性 | 内容 |
|------|------|
| **身份** | 大法师的妹妹 |
| **核心能力** | 特殊封印能力 — 天生就能容纳和中和黑暗能量 |
| **与主角关系** | 前世存在深厚羁绊 |
| **剧情定位** | 全游戏绝对核心角色 |

### 角色意义
- 她是黑暗神「最理想的容器」——这一事实贯穿整个故事
- 她的存在既是希望（封印黑暗神的关键）也是诅咒（永无安宁）
- 她的选择定义了这个故事的情感核心：「牺牲」vs「重逢」

### 性格关键词
- 温柔而坚韧
- 面对命运时选择微笑
- 记住一切的人

## 大法师

| 属性 | 内容 |
|------|------|
| **身份** | 大陆最强法师之一 |
| **与女主关系** | 女主的哥哥 |
| **核心知识** | 掌握世界真相，知道女主最终仍然存在于某处 |

### 角色意义
- 扮演「引路人」角色——他知道的比主角多得多
- 驱动着他的是对妹妹的愧疚与爱
- 在故事中连接过去（封印战争）与现在（世界修复）
- 后日谈中重新集结队伍的发起者
