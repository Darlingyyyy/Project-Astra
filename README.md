## 世界观

**艾尔德拉大陆** — 由神树之力、秩序之力、深渊之力三种力量维持平衡的世界。

远古时代，黑暗神诞生，一位少女以自身为封印容器将其封印。如今封印动摇，轮回的记忆开始在普通人梦中浮现……

## 核心玩法

- **三人小队即时动作战斗** — 随时切换操控角色
- **五职业体系** — 战士 / 狂战士 / 游侠 / 法师 / 牧师
- **元素连携系统** — 冰冻+重击=碎冰爆发，燃烧+箭矢=爆燃
- **双结局叙事** — 一周目 + 真结局，选择与牺牲

## Demo 目标

- 1 个可探索区域（神树森林 + 新手村）
- 5 小时主线剧情
- 3 个 Boss 战
- 20 个任务

## 开发原则

1. 剧情先行，玩法原型验证，再铺系统
2. 先做可玩 Demo，再扩展
3. 不做超大开放世界，不做几十个职业，不做抽卡
